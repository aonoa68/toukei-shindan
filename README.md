# 統計情報で社会・経済を診断する

立教大学「統計情報で社会・経済を診断する」（2022〜2025年度担当）の授業資料サイトです。過去の授業の記録として公開しています。

- 公開URL: https://aonoa68.github.io/toukei-shindan/
- 担当授業の一覧: https://aonoa68.github.io/teaching/

MkDocs Material で作っています。`docs/` は生成物です（元の資料フォルダからマニフェスト経由で作成）。

```bash
mkdocs serve       # 手元で確認
mkdocs gh-deploy   # 公開（gh-pages ブランチへ）
```

資料の著作権は作成者（小野原 彩香）にあります。資料中に引用した図表・統計の権利は、それぞれの出典元に帰属します。
