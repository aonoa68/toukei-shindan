# 第10回　文章から社会・経済を診断する

テキストマイニングの実例、形態素解析（MeCab など）と辞書、N-gram、Zipf の法則、タイプ・トークン比、TF-IDF を解説し、後半では Word2Vec・BERT・GPT など大規模言語モデルと従来手法の違い、AI を活用したテキストマイニングの方向性を紹介します。
