# 第3回　基本統計量に関する演習

e-Stat から国勢調査の都道府県別人口をダウンロードし、Google Colaboratory と ChatGPT を使って合計・平均・最大最小、度数分布表とヒストグラム、箱ひげ図、分散、散布図、相関係数を求める演習です。

!!! note "この回について"
    授業で配布した整形済みCSV（3_classwork.csv）は手元に残っていないため、同じ国勢調査データを収めた2022年度版のExcelファイルを代わりに掲載しています。スライドの手順どおり e-Stat から取得することもできます。
