# 第8回　地理情報を持つ統計情報から社会・経済を診断する

地理情報システム（GIS）の概要、緯度経度座標系と測地系（日本測地系・世界測地系）、平面直角座標系・UTM座標系と地図投影法、EPSGコードを体系的に説明し、地理院地図・jSTAT MAP・OpenStreetMap・Leaflet・QGIS などのツールとデータの入手先を紹介します。
