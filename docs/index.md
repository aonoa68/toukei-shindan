# 統計情報で社会・経済を診断する

*Statistical Analysis of Society and Economy*

立教大学で2022〜2025年度に担当した授業の資料です。ここに置いているのは主に **2025年度** の版です。

!!! info "過去の授業の記録です"
    この授業は現在は開講していません。成績評価や試験に関するページ、一部の図版は、公開にあたって省いています。
    それ以外は当時のままで、統計データや制度の記述、提出方法の案内などは作成時点のものです。

## この授業について

社会や経済に関する調査・指標を読み解くための基礎として、e-Stat や RESAS など公的機関が公表する統計データの種類と使い方を紹介します。基本統計量、時系列データ、構成比・寄与度・物価指数といった経済指標を学んだあと、GIS（地理情報システム）、テキストマイニング、Kaggle を例にしたデータ分析コンペティションへと進みます。講義回と演習回を交互に行い、演習では Google Colaboratory 上の Python と生成AIを使って実際にデータを分析します。
