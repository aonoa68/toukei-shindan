# 第2回　社会・経済統計へのアクセス

「統計」という語の意味と歴史、日本の統計機構（分散型・集中型）と総務省統計局の役割、データの質、1次データと2次データの違いと収集時の注意点を整理し、e-Stat・RESAS・V-RESAS でできることを紹介します。
